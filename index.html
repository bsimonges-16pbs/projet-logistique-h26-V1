Module Achats & Automatisation

Workflow cible : Brouillon → À valider → Envoyé → Reçu → Clos.

BrouillonCréé automatiquement si net < seuil et fournisseur actif.
À validerContrôle achat / garde-fous / anti-duplication.
EnvoyéCommande transmise au fournisseur.
ReçuRéception enregistrée par le magasinier.
ClosPO terminée, auditée et archivée.

Règles d’automatisation

  1. IF classe A AND net < seuil AND fournisseur actif THEN créer PO brouillon + log.
  2. IF stockout AND fournisseur actif THEN priorité urgente + alerte critique.
  3. IF fournisseur inactif THEN bloquer la création PO automatique et créer exception.
  4. IF PO déjà ouverte pour le même SKU THEN ne pas dupliquer.
  5. IF quantité suggérée > 3×EOQ THEN exiger validation manuelle.
  6. IF article classe C AND faible impact THEN regrouper dans une vague standard.
